# BANXE AI BANK — Product Requirements Document

## 1. Product Overview
AI-powered neobank for fiat & crypto, EMI-licensed (UK FCA).
Target: tech-savvy users 25-45, digital nomads, crypto-native professionals.

## 2. Personas
| Persona | Description | Primary Need |
|---------|-------------|-------------|
| Alex (Freelancer) | 32, remote worker, paid in crypto | Seamless fiat-crypto conversion |
| Maria (SME Owner) | 41, e-commerce, multi-currency | AI spending insights, fraud alerts |
| Dev (Crypto Native) | 28, DeFi user, wants banking | Unified dashboard, compliance |

## 3. Core Features
- W-01 Dashboard: balance, AI insights, quick actions, transaction feed
- W-02 Transactions: history, AI categorization, search/filter, export
- W-03 Wallets: fiat & crypto side by side, balance charts
- W-04 Send Money: 3-step progressive disclosure, real-time FX
- W-05 AI Assistant: chat with financial context, confidence levels
- W-06 Profile: KYC status, security settings, dark mode ONLY

## 4. Success Metrics
| Metric | Target |
|--------|--------|
| Onboarding completion | >85% |
| DAU/MAU | >40% |
| AI insight interaction | >60% |
| Transaction completion | >95% |
| WCAG 2.2 AA | 100% |

## 5. Constraints
- EMI license (UK FCA), WCAG 2.2 AA, dark mode only
- TypeScript strict, no hardcoded credentials
- Payment flows: max 3 fields per screen
- AI insights: always show confidence level
